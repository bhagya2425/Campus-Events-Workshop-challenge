# Campus Events – Workshop Challenge

## Problem Statement

Develop a simple, responsive and user-friendly **College Events Registration Portal** for students across all branches of the college.

The platform should allow students to explore technical and non-technical events, check event details and eligibility requirements, and register for events.

## Main Requirements

### 1. Homepage
- Display the college events portal.
- Provide two categories: Tech Events and Non-Tech Events.

### 2. Tech Events
Display technical events such as:
- AI & Machine Learning Workshop
- Web Development Bootcamp
- Coding Competition
- Technical Hackathon

### 3. Non-Tech Events
Display non-technical events such as:
- Cultural Fest
- Dance Competition
- Singing Competition
- Photography Contest

### 4. Event Information
Every event must display:
- Event name and description
- Date and time
- Venue and room number
- Eligible branches
- Eligible academic years
- Requirements
- Team size
- Registration status

### 5. Branch Eligibility

The platform should support these branches:
- CSE
- CSE (AI & ML)
- CSE (Data Science)
- CSE (IoT)
- ECE
- ISE

Students from 1st, 2nd, 3rd and 4th years should be supported.

Eligibility may differ for each event.

### 6. Registration
Provide a registration form containing:
- Full Name
- USN
- Branch
- Year
- College Email
- Phone Number

The system should check event eligibility before accepting registration.

Display a confirmation message after successful registration.

## Expected Outcome

A working college event portal where students can discover events, understand eligibility, view event information and register for eligible events.

## Suggested Tools

- Google Stitch – UI Design
- Google Antigravity – Development
- Supabase – Database and backend services
- GitHub – Version control
- Vercel – Deployment

**Note:** Students may use suitable alternatives where appropriate.
